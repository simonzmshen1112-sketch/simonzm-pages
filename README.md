# simonzm pages

一个极简静态网页发布仓库，适合放公众号风格文章、读书笔记、长图配套页等内容。

## 本地结构

- `index.html`：站点首页，列出所有文章
- `articles/<slug>/index.html`：单篇文章页面
- `assets/`：共享样式和未来可能需要的图片

## 推荐发布方式

使用 GitHub Pages。

如果仓库名是 `simonzm.github.io`，公开地址通常是：

```txt
https://simonzm.github.io/
```

如果仓库名是 `simonzm-pages`，公开地址通常是：

```txt
https://<你的 GitHub 用户名>.github.io/simonzm-pages/
```

## 后续使用

之后你给 Codex 发文章需求时，可以直接说：

```txt
按 simonzm-pages 的格式，生成一篇手机和电脑都能打开的网页，并发布。
```
